# 招聘数据智能分析系统 —— 项目说明文档

## 一、项目概述

### 1.1 项目背景

随着互联网招聘平台的快速发展，招聘数据中蕴含着丰富的市场趋势和人才需求信息。然而，面对海量的招聘数据，求职者和企业往往难以快速获取有价值的洞察。本项目基于拉勾网 29,500 条真实招聘数据，构建了一套集数据采集、清洗、可视化分析、机器学习与大模型智能交互于一体的招聘数据智能分析系统，旨在为求职者提供精准的就业市场洞察，为企业提供人才需求趋势分析。

### 1.2 项目目标

- **数据驱动决策**：通过多维度可视化分析，直观呈现招聘市场的薪资水平、岗位需求、城市分布等关键指标
- **智能岗位匹配**：利用机器学习聚类与神经网络分类技术，实现岗位的智能归类与预测
- **AI 辅助求职**：基于大模型与 RAG 知识增强，提供个性化的求职建议和岗位推荐
- **企业深度洞察**：多维度分析企业招聘画像，帮助求职者了解目标企业

### 1.3 核心价值

| 价值维度 | 说明 |
|---|---|
| 数据规模 | 29,500 条真实招聘数据，覆盖全国主要城市和主流技术岗位 |
| 分析深度 | 从宏观市场趋势到微观岗位画像，8 个维度深度分析 |
| 智能程度 | 集成大模型对话、RAG 知识增强、神经网络分类等 AI 能力 |
| 实用性 | 简历解析、岗位推荐、薪资预测等功能直接服务于求职场景 |

### 3.4 机器学习分析

#### KMeans 聚类分析

- **输入**：岗位描述文本
- **处理流程**：TF-IDF 特征提取 → KMeans 聚类 → PCA 降维可视化
- **输出**：聚类散点图、簇群关键词、簇群统计表
- **可调参数**：聚类数 K（2-10）

#### 神经网络分类预测

- **模型结构**：三层 MLP（Embedding → 256 → 64 → num_classes），Dropout 0.3
- **训练流程**：Embedding 向量化 → KMeans 伪标签 → MLP 训练
- **特性**：
  - 实时训练进度（后台线程 + 轮询机制）
  - 学习率自动衰减（ReduceLROnPlateau）
  - 最佳模型自动保存
  - 训练曲线可视化（Loss / Accuracy）
  - 分类报告展示
- **可调参数**：聚类数 K、训练轮次、学习率

#### 薪资预测

- **模型**：RandomForest 回归（200 棵树）
- **特征**：城市、学历、工作经验、岗位类别、公司规模、行业领域
- **输出**：预测薪资 + 置信度评估
- **评估指标**：MAE、R²

### 3.5 AI 智能求职助手

| 功能 | 说明 |
|---|---|
| 普通对话 | 基于通义千问的招聘领域问答 |
| RAG 增强对话 | 检索知识库后生成回答，答案更准确 |
| 追问推荐 | 自动推荐相关追问话题 |
| 知识库重建 | 支持重新构建 RAG 知识库 |

**RAG 知识库内容**：
- 全局市场概览
- 城市薪资排行
- 岗位类别薪资对比
- 学历薪资关系
- 硕士 vs 本科对比
- 经验薪资趋势
- 公司规模薪资分析

### 3.6 简历解析与岗位推荐

| 功能 | 说明 |
|---|---|
| PDF 简历上传 | 支持 PDF 格式简历文件 |
| 信息提取 | 自动解析学历、工作年限、技能关键词 |
| 岗位匹配 | 基于技能重合度、学历匹配、经验匹配综合评分 |
| 推荐结果 | 返回 Top10 匹配岗位，含匹配分数和匹配原因 |

**匹配评分规则**：
- 技能重合：每匹配一项 +10 分
- 学历匹配：+20 分
- 经验匹配：+15 分

### 3.7 企业深度画像

选择任意企业，自动生成多维度招聘画像：

| 维度 | 说明 |
|---|---|
| 热门岗位 | 企业招聘岗位类别分布 |
| 城市布局 | 企业招聘城市分布 |
| 学历偏好 | 企业学历要求偏好 |
| 薪资水平 | 企业薪资分布区间 |
| 行业覆盖 | 企业涉及行业领域 |
| 经验要求 | 企业工作经验要求分布 |

### 3.8 分析报告导出

一键生成 HTML 格式的专业招聘分析报告，包含：
- 核心指标概览
- 薪资排行分析
- 岗位需求统计
- 学历分布情况
- 薪资区间分析
- 数据洞察总结

支持按城市和岗位类别筛选报告内容。

## 七、快速部署

### 7.1 环境要求

- Python 3.11+
- Node.js 18+
- Conda（推荐）

### 7.2 安装步骤

```bash
# 1. 创建 Python 虚拟环境
conda create -n recruitment python=3.11
conda activate recruitment

# 2. 安装后端依赖
pip install -r requirements.txt

# 3. 安装前端依赖
cd frontend
npm install
cd ..
```

### 7.3 配置

在系统环境变量中设置阿里云百炼 API Key：

```
变量名: DASHSCOPE_API_KEY
变量值: 你的API Key
```

> 获取方式：登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/) → API Key 管理 → 创建

### 7.4 启动

**方式一：一键启动**
```bash
start.bat
```

**方式二：分别启动**
```bash
# 终端1 - 启动后端
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000

# 终端2 - 启动前端
cd frontend
npm run dev
```
